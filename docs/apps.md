# Приложения, которые не ставятся install.sh

Ставятся вручную, со своими репозиториями (после переустановки добавьте их сами):

- Docker (docker-ce, compose-plugin): https://docs.docker.com/engine/install/debian/
- Visual Studio Code: https://code.visualstudio.com/docs/setup/linux
- Bitwarden (deb с bitwarden.com), автозапуск настраивается в `~/.config/autostart`
- Claude Desktop
- DBeaver CE: https://dbeaver.io/download/
- Inkscape, Bottles (flatpak `com.usebottles.bottles`), OpenRGB

Настройки этих программ (профили, пароли, токены) в репозиторий не входят.
