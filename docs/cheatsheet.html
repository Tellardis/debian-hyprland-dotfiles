Шпаргалка Hyprland

Super = клавиша Windows · конфиг: ~/.config/hypr/hyprland.lua

Приложения и окна

Super+QТерминал (alacritty)
Super+RЛаунчер (fuzzel)
Super+CЗакрыть окно
Super+VПлавающее / обычное окно
Super+TСменить направление деления (togglesplit)

Размер и пропорции окон

Super+Alt+HТекущее окно уже
Super+Alt+LТекущее окно шире
Super+ПКММенять размер мышью (зажать)
Super+ЛКМПеретаскивать окно (зажать)
Новое окно делит экран примерно 2/3 на 1/3 (default_split_ratio = 1.33).

Фокус

Super+HВлево
Super+JВниз
Super+KВверх
Super+LВправо
Стрелки тоже работают (через Fn-слой клавиатуры).

Рабочие столы и мониторы

Super+1…9, 0Перейти на стол 1–10 (0 = 10)
Super+Shift+1…9, 0Перенести окно на стол
Super+Ctrl+H / LОкно на монитор слева / справа

Сессия и экран

Super+Shift+LБлокировка (hyprlock)
Super+MВыйти из Hyprland (hyprshutdown)
Super+Shift+CПипетка: цвет в буфер (hex)
hypridle: блокировка через 10 мин, экран гаснет через 15 мин. hyprsunset: тёплый свет с 21:00, обычный с 7:00.

Скриншоты

PrintОбласть: файл + буфер обмена
Shift+PrintВесь экран в файл
Файлы лежат в ~/Pictures/Screenshots/

Звук и обои

Super+F9Наушники ⇄ колонки
ПКМ по звуку в waybarТо же самое
Super+F10Следующие обои (сами каждые 15 мин)
Vol+ / Vol−Громкость ±5 %
MuteЗвук вкл / выкл

Раскладка

Alt+Shiftus ⇄ ru
Ctrl+Shift+C / VКопировать / вставить в alacritty (и на ru)

Neovim (LazyVim)

Ctrl+D / UПол-экрана вниз / вверх
Ctrl+F / BЭкран вниз / вверх
gg / GНачало / конец файла
{ / }Абзац вверх / вниз
/словоПоиск (n / N: дальше / назад)
Space u mРендер markdown вкл / выкл
Space c pПредпросмотр markdown в браузере

Вход в систему

GRUB, пункт 1: экран входа tuigreet (tty2), логин запоминается, Hyprland стартует сам
GRUB, «Debian GNOME»: запасной вход через GDM
Ctrl+Alt+F1: запасной tty-логин (тоже запускает Hyprland)
tty3: логин тоже запускает Hyprland
