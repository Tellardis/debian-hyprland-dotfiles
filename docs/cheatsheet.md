# Шпаргалка Hyprland (текущий конфиг)

Super = клавиша Windows. Источник: `~/.config/hypr/hyprland.lua`.

## Приложения и сессия
| Клавиши | Действие |
|---|---|
| Super + Q | Терминал (alacritty) |
| Super + R | Лаунчер (fuzzel) |
| Super + C | Закрыть окно |
| Super + V | Окно плавающее / обычное |
| Super + T | Переключить направление раскладки окон (togglesplit) |
| Super + Shift + L | Блокировка экрана (hyprlock) |
| Super + M | Выйти из Hyprland |

## Фокус и рабочие столы
| Клавиши | Действие |
|---|---|
| Super + H/J/K/L | Фокус влево/вниз/вверх/вправо (vim); стрелки тоже работают через Fn-слой |
| Super + 1…9, 0 | Перейти на рабочий стол 1–10 (0 = 10) |
| Super + Shift + 1…9, 0 | Перенести окно на стол 1–10 |
| Super + Ctrl + H / L | Перенести окно на монитор слева / справа |
| Super + Alt + H / L | Текущее окно уже / шире (новое окно делит экран 2/3 на 1/3) |

## Мышь
| Действие | Результат |
|---|---|
| Super + ЛКМ (зажать) | Перетаскивать окно |
| Super + ПКМ (зажать) | Менять размер окна |

## Скриншоты
| Клавиши | Действие |
|---|---|
| Print | Выделить область: файл в `~/Pictures/Screenshots/` + буфер обмена |
| Shift + Print | Весь экран в файл (без буфера) |

## Звук
| Клавиши | Действие |
|---|---|
| XF86AudioRaiseVolume / LowerVolume | Громкость ±5 % |
| XF86AudioMute | Выключить / включить звук |

## Раскладка
| Клавиши | Действие |
|---|---|
| Alt + Shift | us ⇄ ru |

## Автоматически (hypridle)
- Через 10 минут простоя: блокировка.
- Через 15 минут: монитор гасится (DPMS off).

## Вход в систему
- GRUB, пункт 1: экран входа tuigreet (tty2), имя запоминается → Hyprland стартует сам.
- Ctrl+Alt+F1: запасной tty-логин (тоже запускает Hyprland).
- GRUB, пункт «Debian GNOME»: запасной вход через GDM.
- tty3: логин тоже запускает Hyprland.
| Super + F9 (или ПКМ по звуку в waybar) | Переключить вывод звука: наушники / колонки |
| Super + F10 | Следующие обои (сами меняются каждые 15 минут) |
| Super + Shift + C | Пипетка: выбрать цвет на экране (hex в буфер и уведомление) |
